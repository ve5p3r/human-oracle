Pricing Tiers

Free reads for discovery, USDC for verified answers.

Free
$0
  • hasAnswer() — check existence
  • getAnswerMeta() — count, tags, votes
  • getAnswersByTag() — browse by topic
  • No gas (view functions)
Premium
1 USDC
  • getVerifiedAnswer() — full answer
  • Content hash (keccak256)
  • Source URL + vote count
  • Tamper-proof verification
Challenge
0.5 USDC
  • challengeAnswer() — dispute validity
  • resolveChallenge() — owner adjudicates
  • Upheld → 2x stake returned
  • Economic skin in the game

Search API

Three search modes for different quality/speed tradeoffs.

GET /search?q=reentrancy+guard&mode=search → BM25 keyword (fast) GET /search?q=safe+token+transfer&mode=vsearch → Vector semantic POST /premium/search {query, n} → LLM reranked (best) GET /answer/stackoverflow/12345 → Full document GET /tags → Tag distribution GET /stats → Corpus stats
